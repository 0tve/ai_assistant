# ИИ-помогатор для баз знаний (Тестовое задание).
Ссылка на бота - https://t.me/ai_knowledge_assistant_bot (ID - 8099389705)

Ссылка на таблицу - https://docs.google.com/spreadsheets/d/1wj8nhwbvjh6qGpOAN78QPsvebeDMGK_nxZQVNhKY4Ik

Ссылка на воркфлоу - https://share-n8n.com/shared/tIcBsFmxGpll

### Использованные инструменты:
- Telegram-бот.
    - условие задачи.
- n8n
    - широкий функционал, множество интеграций, хорошая документация и сообщество.
- google sheets
    - условие задачи.
- groq
    - бесплатно, высокая скорость.
- convertapi.com
    - широкий функционал, простота, надежная инфраструктура.
- ocr.space
    - простота, высокое качество.
- detectlanguage.com
    - простота, поддержка многих языков.

### Места, где возникло больше всего трудностей при разработке:
1. Извлечение текста из DOCX-файла.
2. Считывание данных с изображения.

Решение - использовать ноды HTTP Request для подключения к готовым инструментам.

### Возможные улучшения:
1. Обработка краевых случаев и ошибок, добавление ретраев.
2. Улучшение UX в чате с ботом - больше уведомлений, различные опции и параметры, отправка суммаризации в чат.
3. Поддержка считывания множества языков с изображений.
4. Добавление новых колонок в таблицу (кол-во слов).
5. Повышение качества (улучшение промптов, настройка OCR).
6. Добавление нового функционала (поиск по базе знаний, аналитика).
